### Tools written in Rust to help with decrypting, disassembling and decompiling PS3's GTA V game files.

I am making this mostly because no one has solved the Chiliad Mystery yet, and while trying, I realized how the process to navigate game files should be faster and more efficient in 2026.
I feel the strong need to make extra tools to improve on some things and do some new things.

These tools are, as of now, mostly for the PS3 version of GTA V and will only tested on Version 1.00. Since I don't have the Xbox version nor the PC version files, I am not working on compatibility YET. I do want to have them working for other versions as well (like PC and Xbox), but I can't do this alone for sure(not right now). So this probably won't ever be finalized. If you do find a bug while using this on the version 1.00 of the GTA V(PS3) or can help me implement more useful stuff, I would be very happy. :)
Contact me on Discord to talk about bugs or if you want to help in any way: phoonfps
